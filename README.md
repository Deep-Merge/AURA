# AURA

Curated journeys. A portfolio site with a real local booking desk.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Demo accounts

- Traveler: `maya@example.com` / `aura-guest`
- Desk: `admin@example.com` / `aura-desk`

Codes: `AURA10` (10%) and `WELCOME500` ($500). Confirming a booking uses the test desk and does not charge a card.
